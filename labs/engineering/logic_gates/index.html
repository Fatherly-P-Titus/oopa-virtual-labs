The engineering

Combinational logic has no memory: the outputs depend only on the current inputs. Each gate applies a Boolean function; wires carry the result to the next stage.

This lab uses ideal binary levels and instantaneous propagation. Real chips have voltage thresholds, delay and fan-out limits — ignored here so the Boolean structure stays clear.
