# M11.5 — Analysis and Educational Environment

## Implemented results

The Analysis page uses the current operation inputs and existing `HeatExchangerModel.solve_design` result. It displays heat duty, outlet temperatures, LMTD when the active model configuration reports it, effective U, effectiveness, NTU, area, equivalent pressure-drop estimates, energy-balance discrepancy, and duty reduction relative to the same case with fouling removed.

The one-shell-pass configuration uses the supported shell-side E–NTU relation. Its LMTD is deliberately shown as not evaluated. LMTD appears only for supported parallel/counter-current cases with valid terminal differences.

## Calculation-backed charts

- **Temperature profiles:** 11 linear points between each stream's model-derived inlet/outlet temperatures. These are endpoint illustrations; shell-side crossflow and local temperature fields are not resolved.
- **Heat duty vs flow:** two independently model-solved sweeps. Each varies one stream's mass-flow input while holding the other at its current value.
- **Heat duty vs fouling:** 11 model-solved points with hot- and cold-side fouling resistances varied equally.
- **Performance comparison:** grouped duty bars for the supported shell-and-tube and double-pipe calculations. Up to four session-only input cases can be stored; each is recalculated for the compared configurations.

No plotted data are decorative or generated by a separate visual solver. Invalid model inputs clear the charts and analysis values.

## Guided investigations

Six activities load documented starting conditions and give an objective, procedure, and measurable outputs:

1. Flow arrangement.
2. Hot/cold flow-rate investigation.
3. Heat-transfer area.
4. Fouling impact.
5. Shell-and-tube vs double-pipe comparison.
6. Low-flow/high-fouling troubleshooting.

Activities are starting points, not locked workflows. Students can change all operating controls and save comparison cases during the current session.
