# Flow and thermal visualization

M11.4 connects the validated heat-exchanger model to equipment outlet readings and restrained temperature tints. The double-pipe view changes its annular flow direction with the selected parallel or counter-current arrangement; shell-side and tube-side cues use the documented one-shell-pass/two-tube-pass educational configuration.

Animated markers and arrows are representative stream-path cues. They are not CFD, resolved local velocity, or local temperature fields. Invalid operating inputs clear model readings and suppress temperature/flow overlays.
